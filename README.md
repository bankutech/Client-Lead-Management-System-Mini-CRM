# 💼 Client Lead Management System (Mini-CRM)

A lightweight, full-stack Customer Relationship Management (CRM) dashboard for tracking client leads, managing interactions, and analyzing sales pipelines.

## 🚀 Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** SQLite

## ✨ Key Features
- **Lead Tracking:** Add, edit, and manage client leads through their lifecycle.
- **Dashboard Analytics:** Visualize lead statuses and conversion rates.
- **Fast & Responsive:** Powered by Vite and Tailwind CSS for lightning-fast performance and a modern UI.
- **Local Database:** Uses SQLite for easy setup and persistent local storage.
